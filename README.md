# Bank Marketing Prediction using Decision Tree Classification

## Overview

This project explores the use of **Decision Tree Classification** to predict whether a bank customer will subscribe to a term deposit based on marketing campaign data.

The project demonstrates a machine learning classification workflow, from exploring customer data to preparing a model for prediction.

## Objectives

- Explore and understand bank marketing campaign data.
- Prepare the dataset for machine learning.
- Apply Decision Tree Classification to a binary classification problem.
- Evaluate the model's predictive performance using the metrics implemented in the notebook.

## Machine Learning Approach

**Algorithm:** Decision Tree Classifier

Decision Trees learn decision rules from input features and use them to classify observations into target categories. They are useful for understanding how different customer characteristics relate to a prediction.

## Dataset

The project uses bank marketing data containing customer and campaign-related information. The target is whether a customer subscribes to a term deposit.
